# Gauntlet results

Live runs of the Agent Gauntlet against real agents. Each test is an adversarial scenario delivered through the MCP tools themselves; the oracle scores the agent's recorded tool calls, never its words.

This page is generated by `harness/gen_results.py` from `runs/history.jsonl` (the verdict record), `runs/ledger.json` (run context), and the per-test session logs. It is not hand-edited.

## How to read this

- A verdict is a snapshot of one agent on one day, not a permanent grade. Agents, models, and the harness all change.
- **Latest** is the most recent verdict per test. **Runs** counts every live run of that test, including runs that failed to measure.
- **INCONCLUSIVE** means the run recorded no usable evidence: the agent never reached the tools, or the clean baselines disagreed so the oracle could not tell steering from nondeterminism. It is not a pass and not a fail.
- A test whose INCONCLUSIVE share is over half across at least 3 runs is flagged **WEAK**: the scenario needs rewriting, not more runs.
- Runs that failed because the harness itself was broken (rather than the test) still count in Runs and in the INCONCLUSIVE share, so a WEAK flag can reflect harness failures as well as test weakness; the run notes in the ledger say which runs those were.
